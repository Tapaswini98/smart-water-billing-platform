## Restoring

Custom-format dumps need `pg_restore`, not `psql`:

```bash
scripts/verify-restore.sh --file backups/sample-20260920T150139Z.dump   # safe: throwaway container
scripts/restore.sh --file backups/sample-20260920T150139Z.dump --yes    # destructive: replaces the target
```

The dump includes `__EFMigrationsHistory`, so EF Core sees no pending
migrations after a restore and startup migration is a no-op.
